# Common

Shared component specs, connector pinouts, and wiring standards that apply
across all hardware subsystems.

- Connector standard: Molex Micro-Fit 3.0 (8-pin) for encoder + CAN + power
- Bus wire gauge: 12 AWG for 48 V runs, 16 AWG for per-joint spurs
- Grounding: star ground at MCU board; motor return via dedicated GND wire
